**Background & Solution**: Targeted high concurrency and unbalanced load issues across massive edge cloud nodes. Designed and implemented an adaptive cloud resource scheduling system CacheFlux based on reinforcement learning, DNNs, and linear programming.

**Results**: Successfully deployed in real-world edge scenarios at Baishanyun Technology. Solved high-dimensional resource scheduling near-optimally within one minute, significantly improving overall system allocation stability.

## Tech Stack

- Reinforcement Learning
- Deep Neural Networks (DNN)
- Linear Programming & Combinatorial Optimization
- Cloud Resource Allocation Framework
